# security policy

## supported versions

only the latest released version of `leaneq` gets security updates and bug fixes.

| version | supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## reporting a vulnerability

if you find a security issue in `leaneq` (for example in the ipc named pipe framing, preset parsing, or memory handling), please don't open a public github issue.

instead, report it privately through **github private vulnerability reporting** (under the **security and quality** tab -> **report a vulnerability**).

please include:
- what the issue is and what it could break
- steps to reproduce it
- your `leaneq` and windows versions

i'll try to get back to you within a few days :)
